# Airbnb PyFGroup— Frontend

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4.

```bash
cp .env.example .env.local
npm install
npm run dev      # http://localhost:3000
```

Estructura por funcionalidades: cada carpeta de `src/features/*` agrupa sus
`components`, `hooks`, `services`, `schemas` y `types`. La documentación completa
está en el README de la raíz del proyecto.
